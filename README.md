# AES-128 File Encryptor/Decryptor 🔐

A lightweight and fast Python tool for encrypting and decrypting files using the Advanced Encryption Standard (AES) in Counter Mode (CTR). 

## Features
* Secure AES-128 encryption.
* Requires a strict 16-character key.
* Chunk-based file processing (handles large files without consuming RAM).
* Built-in error handling for missing files and permissions.
